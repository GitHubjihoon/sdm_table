# 스드메의 문단속

구글 시트 비교표를 웹으로 옮긴 페이지입니다. GitHub Pages에 올리고, 데이터는 Firebase(무료 Spark 플랜)에 저장되어 두 사람이 실시간으로 같이 봅니다.

## 파일 구성

| 파일 | 역할 | GitHub에 올리기 |
| --- | --- | --- |
| `index.html` | 화면 | O |
| `app.js` | 동작 (계산, 저장, 로그인) | O |
| `config.js` | Firebase 접속 설정 | O |
| `firestore.rules` | 보안 규칙 (Firebase 콘솔에 붙여넣기용) | 안 올려도 됨 |

`config.js`가 비어 있으면(기본값) **데모 모드**로 동작해서, Firebase 없이도 화면을 미리 확인할 수 있습니다. 이 경우 데이터는 해당 브라우저에만 저장됩니다.

---

## 1단계. Firebase 프로젝트 만들기 (약 10분)

1. https://console.firebase.google.com 접속 → **프로젝트 추가** → 이름 입력 (예: `sdm-table`)
   - Google 애널리틱스는 꺼도 됩니다.
   - 요금제는 기본값인 **Spark(무료)** 그대로 둡니다. 카드 등록이 필요 없습니다.
2. **웹 앱 등록**: 프로젝트 개요 화면에서 `</>` 아이콘 클릭 → 앱 이름 입력 → 등록
   - 화면에 나오는 `firebaseConfig = { ... }` 값을 복사해 `config.js`의 같은 부분에 붙여넣습니다.
   - Firebase Hosting 설정은 체크하지 않습니다 (GitHub Pages를 쓰므로).
3. **Firestore 만들기**: 왼쪽 메뉴 빌드 → **Firestore Database** → 데이터베이스 만들기
   - 위치: `asia-northeast3 (서울)` 권장 (나중에 변경 불가)
   - 모드: **프로덕션 모드**
4. **보안 규칙 적용**: Firestore → **규칙** 탭 → `firestore.rules` 내용을 전부 붙여넣기
   - `me@gmail.com`, `partner@gmail.com`을 두 분의 실제 Google 계정 이메일로 바꾼 뒤 **게시**
5. **Google 로그인 켜기**: 빌드 → **Authentication** → 시작하기 → Sign-in method → **Google** 사용 설정 → 저장

## 2단계. GitHub Pages 배포 (약 5분)

1. GitHub에서 새 저장소 생성 (예: `sdm-table`)
2. `index.html`, `app.js`, `config.js` 업로드 (Add file → Upload files)
3. 저장소 **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `/ (root)` → Save
4. 1~2분 뒤 `https://<깃허브아이디>.github.io/sdm-table/` 주소로 접속 가능

## 3단계. 승인된 도메인 추가 (빠뜨리기 쉬움)

Firebase 콘솔 → Authentication → **설정** 탭 → **승인된 도메인** → 도메인 추가
→ `<깃허브아이디>.github.io` 입력

이걸 안 하면 로그인 시 "unauthorized-domain" 오류가 납니다.

## 4단계. 처음 접속

1. 배포 주소 접속 → **Google로 로그인**
2. 처음 로그인하면 구글 시트 데이터가 자동으로 저장됩니다.
3. 배우자도 같은 주소로 접속해 로그인하면 같은 표를 실시간으로 보고 고칠 수 있습니다.

## 사용법

- **선택 체크박스**: 켜고 끄면 최종 정산이 바로 다시 계산됩니다.
- **금액·업체명·비고**: 칸을 클릭해서 고치고 Enter 또는 다른 곳 클릭 시 저장됩니다.
- **유형**에 따라 "기준가 대비"가 자동 계산됩니다.
  - `기준`: 구분별 기준 업체 (구분당 하나, 새로 지정하면 기존 기준은 `대체`로 바뀜)
  - `대체`: 기준 업체 대신 고를 수 있는 업체 → 기준 금액과의 차액 표시
  - `추가`: 이모님, 지정비용처럼 더해지는 옵션 → 금액 그대로 가산
  - `할인`: 마이너스 금액
- 구분 이름은 회색 줄의 이름을 클릭해서 바꿀 수 있고, `+ 항목 추가` / `+ 구분 추가`로 늘릴 수 있습니다.

## 구글 시트와 달라진 점

- 최종 정산에 **할인 행이 포함**됩니다. 원본 시트는 3,120,000원이었지만 할인 −100,000원이 빠져 있어서, 웹에서는 3,020,000원으로 나옵니다.
- 비고의 `(+11)`, `(+23)` 같은 수동 표기는 "기준가 대비" 열이 자동 계산하므로 뺐습니다.

## 자주 생기는 문제

| 증상 | 원인 / 해결 |
| --- | --- |
| 로그인 버튼을 눌러도 오류 | 3단계 승인된 도메인 확인 |
| "접근 권한이 없습니다" | `firestore.rules`의 이메일 오타 확인 후 다시 게시 |
| 계속 데모 모드로 나옴 | `config.js`에 실제 값을 넣었는지, 그 파일을 GitHub에 다시 올렸는지 확인 |
| 하루 동안 저장이 안 됨 | 무료 한도 초과 (이 용도로는 사실상 발생하지 않음). 한국 시간 오후 4~5시에 초기화 |
